# 提前解除姿态制动：离线闭环验证

状态：**仅离线实现，未接入飞控、未写校准参数、未改变现有 interaction。**
2026-09-03 的验证表明：名义模型能提前回水平、避免反向；模型偏差下仍存在失败，不能据此声称实机平稳停止。

## 做了什么

- `predictive_brake_release.py`：每 10 ms 比较“现在回水平”和“再制动 10 ms 后回水平”。
- 输入当前沿运动方向速度、实际倾角、角速度、原始测量时间戳，以及已经发送、可能仍在传输/姿态响应延迟中的命令。
- 先传播旧测量至决策时刻，再预测后续至少 0.8 s。不是只看当前速度，也不是把旧状态改成当前时间。
- 如果再制动一个周期将使预测最小速度低于探索性余量 0.08 m/s，就提前回水平。回水平后锁定，不再重复打反向脉冲。
- 只允许模拟的反向 20° 制动或水平，不产生正向补偿脉冲，不选择位置目标，也不模拟位置接管。
- `braking_validation_simulator.py`：独立 RK4 数值 plant；命令按延迟后的准确时刻生效。决策改变后，后续状态由 plant 自己计算，绝不重新套用原日志未来的运动。
- `validate_predictive_brake_release.py`：成对比较固定 240 ms 与预测式回水平，每次回水平后继续观察至少 1.5 s。

无效/过旧状态、时间倒退、超时会使离线策略锁定水平；这不是实机故障处置接口，不替代现有定位或飞行安全处理。

## 模型和评分

模拟的单轴模型：

```text
theta'' = wn² (gain * delayed_command + bias - theta) - 2*zeta*wn*theta'
v'      = motion_gain * g * tan(theta)
p'      = v
```

预测器采用解析姿态响应；验证 plant 采用独立数值积分。两者在名义情况下仍共用模型参数，因此只能算实现一致性检查，不是独立物理验证。

评分检查约 1 ms 的全部积分边界，不仅检查 100 Hz 决策点：

- 未反向：沿原运动方向速度始终不低于数值容差 −1e−6 m/s。
- 低速水平状态：未反向，且最后 100 ms 的速度在 0–0.20 m/s、倾角不超过 3°、角速度不超过 5°/s。
- 近静止：上述条件成立，且最后 100 ms 的速度不超过 0.04 m/s。

**低速水平不等于停稳，也不等于位置控制可以无超调地接管。** 未定义位置目标的这项验证无法证明 coast 停点精度。

## 2026-09-03 验证结果

冻结模型来自 `16-47-29/repeat_summary/frozen_validation/report.json`，没有重新拟合。
从 `16-47-29`、`16-58-11`、`17-25-51` 提取共 7 个制动前状态，初速仅覆盖 0.710–0.790 m/s。
显式排除了 `16-47-29` 的 segment 1 定位异常；`16-58-11` 仍带有其原日志质量限制。

### 名义仿真

| 方法 | 解除制动时刻（自制动开始） | 反向数 | 末段速度 | 近静止数 |
|---|---:|---:|---:|---:|
| 固定制动 | 240 ms | 7/7 | −0.172 至 −0.065 m/s | 0/7 |
| 预测式提前回水平 | 180–200 ms | 0/7 | +0.070 至 +0.128 m/s | 0/7 |

以最新 `17-25-51` 的初始状态为例：预测策略在 180 ms 回水平，比基线早 60 ms；仿真末速度为 +0.083 m/s，固定方案为 −0.159 m/s。这不是重飞后的实测结果，也没有证明已停住。

### 预设敏感性测试

20 种情形包含名义模型、动力学增益、姿态固有频率/阻尼变化、20 ms 额外测量或命令延迟、速度/倾角/角速度偏差，以及两个组合场景。参数范围是探索设置，不是已经识别的实机误差边界。

7 个种子 × 20 种情形 = 140 次预测式模拟：**23 次反向，104 次达到低速水平状态**。这些情形共享种子且互相关联，不能换算为飞行成功率。

| 关键失败场景 | 预测式反向数 | 现象 |
|---|---:|---|
| 姿态固有频率降到 0.7 倍 | 7/7 | 残余姿态衰减更慢；最长回退 12.11 cm |
| 水平加速度增益升到 1.2 倍 | 6/7 | 相同倾角的残余减速更强 |
| 较弱加速度 + 较慢姿态 + 20 ms 延迟 | 7/7 | 自适应把制动延长至 250–280 ms；固定 240 ms 在这组反而 0/7 反向 |

最后一组证明：当前自适应方法**并非每种情况下都优于固定时长**。模型认为还应继续制动，但实际姿态尾部更长，最后仍然制动过量。

12.11 cm 是回水平后观察 1.5 s 的模拟回退，不能直接与真实试验较短观察窗口里的约 5 cm 回退比较。

额外的 0.1/0.2/0.4/0.7/1.0 m/s 水平初态扫描单独标记为 synthetic；这些没有实测初态覆盖，不能混入上述 7 个种子的统计。

## 下一步

1. 根据已有实测数据，给“回水平之后还会损失多少速度”建立保守误差范围；不能只把 0.08 m/s 调大到当前场景全部通过。
2. 用多组可能模型预测残余减速范围，以更不利的一侧决定提前解除制动。当前敏感性情形一旦用于设计，就属于开发集，不再是独立验证集。
3. 在独立数据/情形中验证，然后单独评估固定 coast 终点的位置控制接管。姿态阶段“无反向”和最终“无 overshoot、已停稳”分别验收。
4. 若现有数据无法约束低速、不同方向或不同姿态尾部，应再指定补测；本脚本不启动任何飞行。

## 如何重跑（电脑离线，不是 orchestrator 启动参数）

在仓库根目录运行，输出目录必须不存在：

```bash
venv/bin/python -m Interaction.validate_predictive_brake_release \
  /path/to/lb11_translation_inertia_2026-09-03_16-47-29.json \
  /path/to/lb11_translation_inertia_2026-09-03_16-58-11.json \
  /path/to/lb11_translation_inertia_2026-09-03_17-25-51.json \
  --frozen-report /path/to/repeat_summary/frozen_validation/report.json \
  --exclude lb11_translation_inertia_2026-09-03_16-47-29.json:1 \
  --output /path/to/new_validation_directory
```

`--nominal-only` 只跑名义模型；`--synthetic-speed-sweep` 附加合成速度扫描。
`--release-margin-m-s` 仅供探索，改变后不得继续把旧结果称为此版本的验证。

输出 `README.md`、`report.json`、`trajectories.json`、`decisions.json`；包含输入和实现文件 SHA-256、冻结模型、初始状态、决策原因、延迟与失败场景。
