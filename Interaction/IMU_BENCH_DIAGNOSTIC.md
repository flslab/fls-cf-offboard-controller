# 拆桨 IMU 小测试

这个独立入口只订阅遥测，不解锁电机、不发送位置/姿态指令、不写参数、不启动飞行任务。用于检查接触后的加速度波动及采样敏感性；不会生成或应用新的校准参数。

## 准备与运行

1. 拆除桨叶，保留电池、接触机构和 Vicon 标记点的安装状态。关闭正常 controller/orchestrator 和其他连接该飞机的客户端。
2. 在连接 Crazyradio 的电脑或 Pi 上，进入本仓库并启用已有 Python 环境。需要 `cflib`、`numpy`、`matplotlib`；Vicon 旁路另需 `motioncapture`。
3. 运行下面命令。当前本地 swarm manifest 的 lb11 地址为 `radio://0/100/2M/E7E7E7E706`；如硬件连接不同，应显式传实际 URI。指定的新结果目录不能已存在。

```sh
python -m Interaction.imu_bench_diagnostic collect \
  --uri radio://0/100/2M/E7E7E7E706 \
  --drone-id lb11 \
  --output logs/imu_bench_lb11_01
```

输入 `PROPS_OFF` 确认已拆桨后才连接。每段开始前按 ENTER，记录时间共 100 秒：

Pi 没有 `matplotlib` 时，可在采集命令后加 `--no-report`，先保存原始记录，随后将整个结果目录复制到有画图库的电脑，运行下方 `analyze` 命令。USB 直连可显式指定 `--uri usb://0`，需要确认 USB 上连接的是目标飞控。

| 阶段 | 时长 | 动作 |
|---|---:|---|
| static_before | 20 s | 放稳机身，不触碰 |
| slow_roll | 30 s | 手持缓慢 roll 倾斜约 ±10°，往返几次 |
| gentle_taps | 30 s | 稳定支撑机身，轻推接触头后松开 5–6 次，间隔约 3 秒 |
| static_after | 20 s | 恢复初始姿态和支撑，放稳不碰 |

准备动作期间也持续保存遥测，但不纳入四段统计。随时 Ctrl-C 停止并保留已有记录。电机输出非零、过期、IMU 停止、时钟倒退或本地队列溢出会停止采集并标记失败。工具不能阻止另一个程序控制电机，因此必须关闭其他控制客户端。

固件必须支持 `contactImu` 和 FLS 的 1 ms 日志周期编码；不适用于未经确认的官方固件。默认请求 1 kHz，实际收包率需要报告验证。`--period-ms 2` 可在带宽不足时改用 500 Hz 诊断，但报告不会将其标成通过 1 kHz 检查。不会自动降低频率或更新固件。

## 可选 Vicon

在上述命令后加 `--vicon-host 192.168.1.39`，由独立进程保存原始点云。它不选择 lb11 标记点，不向机载估计器回送位置，也不参与电机检查。点云单位为米，记录相同主机的 monotonic 时间；有扩展接口时另存 Vicon 帧号与延迟。

这些时间不是曝光时间，点云尚未分配身份。后续需要选择正确标记点再作 IMU/Vicon 对比；当前自动报告不声称完成光学质心加速度验证。检查 `session.json` 中 Vicon 记录是否为空，以及 `vicon.error.json`；Vicon 失败不会抹掉 IMU 记录。等待帧阻塞时最多等待 2 秒后终止旁路进程，状态会明确标记。

## 输出与解释

- `packets.jsonl`：逐包保存 gyro（deg/s）、acc（g）、16 位生产时间（ms）、24 位日志时间、主机接收时间和电机输出。四路电机输出与 IMU 合并在同一个 22 字节数据包中，避免高频 IMU 挤占独立电机状态包的带宽；IMU 来自固件锁存快照，电机字段为日志读取时刻的指令值。致错包也保留。
- `session.json`：设备、阶段边界、采集是否完整、出错原因；Ctrl-C 和连接失败均保留。
- `report.html`、`report.json`：三轴加速度/角速度波形、静止均值和标准差、源时间缺口和重复包、采样敏感性。
- `imu_stages.png`、`sampling_comparison.png`：可直接查看的图。
- `vicon.jsonl`：仅启用 Vicon 时保存，可能在强制退出时留下一行不完整 JSON。

重做离线报告（不会连接飞机）：

```sh
python -m Interaction.imu_bench_diagnostic analyze logs/imu_bench_lb11_01
```

报告在连续片段上模拟 10 种相位的 100 Hz 采样，比较其 80 ms 因果平均与高频平均。缺口超过 5 ms 的高频数据不跨段积分，不用不完整窗口。图中选择 Y 轴误差较大的相位，并在 JSON 保留所有相位和片段范围。

**两条线是机体系加速度，不是接触力。** 它们没有姿态旋转、模型推力或外力偏置。不同说明采样敏感，不等于已经解释飞行中的波谷。静止段均值包括重力，前后姿态不同也会改变均值，不能直接据此更新 bias。

`contactImu` 是固件滤波后的值，非芯片原始/软件滤波前信号。该测试不能分离滤波前振动；支撑方式会改变结构响应。电机不转时未复现，不能排除带桨工作时的问题。采集完成和高频质量合格独立显示，不代表物理校准成功。

## 本地验证

```sh
python -m unittest Interaction.tests.test_imu_bench_diagnostic -v
```

覆盖时钟回绕/重复/复位、因果积分和缺口、100 Hz 采样相位、部分日志报告、电机异常、无数据超时，以及模拟四阶段采集。硬件收包率和动作效果需要实际拆桨采集验证。
